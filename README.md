# ربات جستجوی فیلم و سریال (روبیکا)

با فرستادن نام فیلم یا سریال، همهٔ لینک‌های دانلود به‌صورت متن فرستاده می‌شود
(هیچ لینکی به صفحهٔ سایت داده نمی‌شود). عضویت در کانال `@Pari_Movies` اجباری است و
دکمهٔ «📝 انتقاد و پیشنهاد» پیام کاربر را مستقیم به مدیر می‌رساند.

## اجرای همیشگی روی GitHub Actions

این ریپو طوری تنظیم شده که ربات عملاً همیشه روشن باشد، بدون نیاز به لپ‌تاپ یا سرور.

1. در `Settings → Secrets and variables → Actions → New repository secret`
   یک Secret با نام **`RUBIKA_BOT_TOKEN`** بساز و توکن ربات روبیکا را در آن بگذار.
2. تب `Actions` → ورک‌فلوی `rubika-bot` → `Run workflow` را یک بار بزن.
3. از این به بعد کرون خودش هر ۵ دقیقه اجرا را زنده نگه می‌دارد.

تا وقتی Secret ساخته نشود، هر اجرا فقط با پیام «رد شد» تمام می‌شود و خطایی نمی‌دهد.

**محدودیت‌ها:** گیت‌هاب حداکثر ۶ ساعت به هر Job اجازه می‌دهد، پس ربات هر بار ۵:۴۰ کار
می‌کند و اجرای بعدی بلافاصله شروع می‌شود؛ بین دو اجرا ممکن است چند ثانیه تا چند دقیقه
فاصله بیفتد. پیام‌های قدیمی‌تر از ۱۰ دقیقه (مثلاً بعد از یک قطعی طولانی) عمداً جواب داده
نمی‌شوند تا کاربر پیام تکراری نگیرد.

## آمار استفاده (چند نفر از ربات استفاده می‌کنند؟)

آمار در فایل `.bot_stats.json` نگه داشته می‌شود و پایان هر اجرا خودکار در ریپو کامیت
می‌شود، بنابراین بین اجراها گم نمی‌شود.

- **ساده‌ترین راه:** در چت خصوصی خودت با ربات بنویس `/stats` یا «آمار»؛ ربات گزارش می‌دهد.
- **راه دوم:** فایل [`.bot_stats.json`](.bot_stats.json) را در همین ریپو باز کن؛ فیلد
  `searches` کل جستجوها و طول `users` تعداد کاربران یکتا است.

آمار شامل: کل کاربران یکتا، کاربران تازه و فعالِ امروز، کل جستجوها و جستجوهای امروز.
شناسهٔ کاربران ذخیره نمی‌شود؛ فقط هش کوتاه SHA-256 آن‌ها (برای شمارش یکتا) نگه داشته
می‌شود، چون این ریپو عمومی است.

> شمارش از اولین اجرای نسخهٔ دارای آمار شروع می‌شود؛ آمار قبل از آن وجود ندارد.

## فایل‌ها

| فایل | کار |
| --- | --- |
| `rubika_bot.py` | ربات روبیکا (polling، دکمه‌ها، کش، صف هر چت) |
| `source.py` | جستجو و پارس لینک از myf2ms.top و donyayeserial.com |
| `stats.py` | شمارش کاربران و جستجوها + گزارش فارسی برای مدیر |
| `check_bot.py` | چکاپ سلامت (منابع، توکن، کانال، زنده‌بودن، خطاهای لاگ) |
| `telegram_bot.py` | نسخهٔ تلگرام ربات |
| `run_bot.bat` / `install_startup.bat` | اجرای ویندوز + اجرای خودکار هنگام روشن شدن |
| `run_forever.sh` | اجرای همیشگی روی لینوکس/سرور |

## اجرای دستی

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # سپس توکن‌ها را داخل .env بگذارید
.venv/bin/python rubika_bot.py
```

چکاپ روزانه: `.venv/bin/python check_bot.py --notify`
